# Markdown 标题同步

在本地保存或重命名 Markdown 文件时，同步文件名与已有的一级标题。国际化版本需要 **Eidos Lite 0.29.0** 及插件 API **3.7.0**。

在插件管理器安装归档，并在需要的 Space 启用。两个默认开启的设置分别控制“标题变化时更新文件名”和“文件名变化时更新标题”。

- 保存修改后的首个 H1，文件名跟随标题，保留 `.md` 或 `.markdown` 后缀。
- 在本地重命名文件，已有的首个 H1 跟随文件名。
- 没有首个 H1 的文档保持不变。支持单行 Setext H1、UTF-8 BOM、frontmatter 和 CRLF。
- 打开文件、启用插件、仅修改正文或接收云端／局域网更新，不会自动整理旧文件名，也不会创建标题。
- 非法文件名字符替换为空格，Windows 保留名称增加下划线；名称不超过 200 个 UTF-8 字节，已有目标文件不会被覆盖。

宿主隔离执行插件，检查当前文件版本，在重命名时维护 Markdown 链接，并防止插件修改再次触发钩子。失败或过期的变更计划不会撤销普通保存或重命名。遇到重名，请手动重命名或修改标题。

插件没有文件系统、网络、SQLite 或工作区权限，只接收当前文档快照并返回该文档的变更计划。当前移动端宿主不支持此国际化归档；已有旧版安装不受影响。

## 开发

使用公开的 SDK/tools 0.9.0，运行 `pnpm install`、`pnpm check -- --target lite`、`pnpm test` 和 `pnpm run pack`。归档与校验文件位于 `dist/`。
